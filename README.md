# Obsidian 笔记库

个人知识管理仓库。以 Obsidian 双链格式（`[[wikilink]]` + YAML frontmatter）维护，同时用于博客文章创作。

## 目录结构

```
note/
├── README.md            # 本文件：仓库总览
├── 00 - 索引/           # 仓库级索引入口
│   └── 博客文章索引.md
├── 01 - Blog/           # 博客文章（博客系统监控此目录，勿改动命名）
└── 02 - Notes/          # 笔记库
    ├── README.md        # 笔记库导航中枢
    ├── 规范.md          # 笔记库唯一权威规范
    ├── 00 - 收集箱/     # 快速捕获
    ├── 01 - 学习计划/   # 系统学习路径
    ├── 02 - 项目/       # 实践项目
    ├── 03 - 领域/       # 独立技术领域知识
    ├── 04 - 资源/       # 链接、工具、课程
    └── 05 - 模板/       # Templater 模板
```

## 使用说明

1. 用 Obsidian 打开本目录（`d:\documents\note`）作为 vault。
2. 新想法先放 `02 - Notes/00 - 收集箱/`，每周整理归档。
3. 归档规则、命名约定、frontmatter 规范见 [规范.md](02%20-%20Notes/规范.md)。
4. 博客文章放在 `01 - Blog/`，不要改动该目录结构与文件名。

## 同步机制

博客系统监控 `01 - Blog/` 的变化，自动将 Markdown 文件导入 MongoDB 数据库。因此 **`01 - Blog/` 的目录名与文件名为系统约定，不可重命名**。

## 版本管理

本仓库为 git 仓库。整理结构时优先用 `git mv` 保留历史，分阶段提交，可随时回滚。

- 还原基线：`git log --oneline`（整理前的基线提交为 "整理前基线快照"）
