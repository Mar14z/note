## 💡 说明

### 🔧 配置方法

**方法 1：Templater 插件（推荐）**

1. 安装 Templater 插件
2. 设置模板文件夹路径为 `02 - Notes/05 - 模板/`
3. 配置命令触发（如 `/tpl`）
4. 新建笔记时输入触发命令选择模板

**方法 2：QuickAdd 插件**

1. 安装 QuickAdd 插件
2. 为每个模板创建 Macro
3. 绑定快捷键（如 `Ctrl+Shift+I` 触发收集箱捕获）

**方法 3：核心插件**

Obsidian 自带的"模板"核心插件：
1. 设置 → 模板 → 模板文件夹位置：`05 - 模板/`
2. 为每个模板设置快捷键

### 📌 使用建议

- **日常**：用收集箱模板快速捕获
- **学习**：用技术笔记模板整理新知识
- **项目**：用项目笔记模板跟踪项目
- **资源**：用资源收藏模板记录好资源
