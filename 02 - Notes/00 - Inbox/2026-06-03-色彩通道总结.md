## 🎨 色彩空间全景图

```
原始世界
   ↓
┌─────────────────────────────────────┐
│  常用色彩空间                         │
├─────────────────────────────────────┤
│  RGB   显示器标准（红绿蓝）            │
│  BGR   OpenCV 默认（蓝绿红）          │
│  灰度   单通道，亮度信息               │
│  HSV   色相+饱和度+明度（最常用）      │
│  Lab   感知均匀（高级）               │
│  YUV   视频压缩                       │
└─────────────────────────────────────┘
```

---

## 🔄 转换速查表

| 转换 | API | 用途 |
|------|-----|------|
| BGR → RGB | `cv2.COLOR_BGR2RGB` | matplotlib 显示 |
| BGR → 灰度 | `cv2.COLOR_BGR2GRAY` | 边缘检测、特征提取 |
| BGR → HSV | `cv2.COLOR_BGR2HSV` | 颜色追踪、分割 |
| 灰度 → BGR | `cv2.COLOR_GRAY2BGR` | 拼接显示 |
| HSV → BGR | `cv2.COLOR_HSV2BGR` | 显示结果 |

## 📌 BGR vs RGB

**坑点**：OpenCV 用 **BGR**，其他库（matplotlib/PIL）用 **RGB**

```python
import cv2
import matplotlib.pyplot as plt

img = cv2.imread('photo.jpg')  # BGR
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  # 转 RGB 才能用 matplotlib
plt.imshow(img_rgb)
plt.show()
```

**不转 RGB 会出现**：图片颜色怪异（红蓝颠倒）

---

## 📌 灰度图

**是什么**：每个像素只有 0-255 的亮度值（单通道）

**转换**：
```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(gray.shape)  # (H, W) 没有通道维度了
```

**用途**：
- ✅ 边缘检测（Canny）
- ✅ 特征提取（SIFT、ORB）
- ✅ 减少计算量（3 通道 → 1 通道）
- ❌ 不能用于颜色相关任务

**公式**：`Gray = 0.299*R + 0.587*G + 0.114*B`（人眼对绿最敏感）

## 📌 HSV 色彩空间（重点）

**H（Hue）色相**：颜色类型，0-180°（OpenCV 减半）
**S（Saturation）饱和度**：颜色鲜艳程度，0-255
**V（Value）明度**：颜色明暗，0-255

```python
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
```

**为什么 HSV 重要？**
- RGB 受光照影响大
- HSV 中 V 是亮度，HS 不受光照影响
- **最适合做颜色追踪**

### 经典用法：检测某种颜色

```python
# 蓝色范围（OpenCV HSV 范围）
lower_blue = np.array([100, 50, 50])
upper_blue = np.array([130, 255, 255])

# 创建掩码
mask = cv2.inRange(hsv, lower_blue, upper_blue)

# 提取蓝色区域
result = cv2.bitwise_and(img, img, mask=mask)
```

### 常用颜色 HSV 范围

| 颜色 | H 范围 | S 范围 | V 范围 |
|------|--------|--------|--------|
| 🔴 红 | 0-10, 170-180 | 50-255 | 50-255 |
| 🟢 绿 | 35-85 | 50-255 | 50-255 |
| 🔵 蓝 | 100-130 | 50-255 | 50-255 |
| 🟡 黄 | 20-35 | 50-255 | 50-255 |
| ⚪ 白 | 任意 | 0-30 | 200-255 |
| ⚫ 黑 | 任意 | 0-255 | 0-30 |

## 🛠️ 实战代码模板

### 1. 颜色检测器

```python
import cv2
import numpy as np

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret: break
    
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    
    # 检测蓝色
    lower = np.array([100, 50, 50])
    upper = np.array([130, 255, 255])
    mask = cv2.inRange(hsv, lower, upper)
    result = cv2.bitwise_and(frame, frame, mask=mask)
    
    cv2.imshow('Original', frame)
    cv2.imshow('Mask', mask)
    cv2.imshow('Result', result)
    
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

### 2. 多通道分离与合并

```python
# 分离
b, g, r = cv2.split(img)

# 分别显示
zeros = np.zeros_like(b)
blue_only = cv2.merge([b, zeros, zeros])  # 只看蓝色通道
green_only = cv2.merge([zeros, g, zeros])
red_only = cv2.merge([zeros, zeros, r])

# 合并
merged = cv2.merge([b, g, r])
```

## 🐛 常见坑

| 坑 | 解决方案 |
|----|---------|
| 颜色检测不到 | 调整 HSV 范围，用滑动条实时调 |
| OpenCV HSV 的 H 是 0-180 | 不是 0-360，要除以 2 |
| matplotlib 显示奇怪 | 记得 BGR → RGB |
| 受光照影响 | 用 HSV 而非 RGB |
| 红色范围特殊 | 红色跨 0°，要分两段（0-10 和 170-180）|

---

## 📚 一句话总结

> **RGB/BGR 是显示器语言，HSV 是人眼语言，灰度是简化版**
> **颜色追踪用 HSV，边缘检测用灰度，特殊需求才转 Lab/YUV**
