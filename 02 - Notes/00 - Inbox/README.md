# 📥 Inbox - 快速捕获

> 所有不确定归类的临时笔记都先放在这里
> **每周日整理一次**！

---

## 🎯 用途

Inbox 是**临时存储区**，用于：
- 快速记下灵感
- 收藏但不整理的内容
- 不确定该放哪个分类的笔记
- 临时任务记录

## 📋 使用规则

### ✅ 什么时候放 Inbox
- 看到一个不错的内容，但不知道放哪
- 临时想法、灵感
- 临时任务（要立刻记录，但不一定要做）
- 任何"以后再整理"的内容

### ❌ 不要放 Inbox
- 已经分类清楚的内容
- 重要项目笔记
- 学习计划（直接放 01 - Learning/）
- 已知领域的技术笔记（直接放 03 - Areas/）

## ⏰ 整理时间

| 频率 | 时间 | 动作 |
|------|------|------|
| 每天 | - | 添加新想法 |
| 每周日 | 5 分钟 | 分类归档 |
| 每月末 | 15 分钟 | 清理过时的 |

## 📁 命名规范

```
YYYY-MM-DD-标题.md
```

示例：
- `2026-06-03-Transformer想法.md`
- `2026-06-05-某书推荐.md`
- `2026-06-10-临时任务.md`

## 🔄 归档决策

每条 Inbox 笔记都问自己：

```
这条内容是什么？
├── 学习相关 → 01 - Learning/<领域>/README.md
├── 技术细节 → 03 - Areas/<领域>/<笔记>.md
├── 项目相关 → 02 - Projects/<项目>/README.md
├── 资源收藏 → 04 - Resources/<类型>.md
└── 不重要 → 删除
```

## 📊 当前 Inbox 状态

> 此处可以使用 Dataview 显示所有未归档笔记：

```dataview
LIST
FROM "00 - Inbox"
WHERE file.name != "README"
SORT file.ctime DESC
```
