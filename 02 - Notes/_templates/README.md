## 🔧 配置方法

### 方法 1：Templater 插件（推荐）

1. 安装 Templater 插件
2. 设置模板文件夹路径为 `02 - Notes/_templates/`
3. 配置命令触发（如 `/tpl`）
4. 新建笔记时输入触发命令选择模板

### 方法 2：QuickAdd 插件

1. 安装 QuickAdd 插件
2. 为每个模板创建 Macro
3. 绑定快捷键（如 `Ctrl+Shift+I` 触发 Inbox 捕获）

### 方法 3：核心插件

Obsidian 自带的"模板"核心插件：
1. 设置 → 模板 → 模板文件夹位置：`_templates/`
2. 为每个模板设置快捷键
