### 任务 2：目标检测

**任务定义**：定位并识别图片中的多个目标

**基础概念**：

```python
# IoU (交并比)
def iou(box1, box2):
    x1, y1, x2, y2 = box1
    x3, y3, x4, y4 = box2
    inter_x1 = max(x1, x3)
    inter_y1 = max(y1, y3)
    inter_x2 = min(x2, x4)
    inter_y2 = min(y2, y4)
    inter_area = max(0, inter_x2 - inter_x1) * max(0, inter_y2 - inter_y1)
    box1_area = (x2-x1) * (y2-y1)
    box2_area = (x4-x3) * (y4-y3)
    return inter_area / (box1_area + box2_area - inter_area)

# NMS (非极大值抑制)
def nms(boxes, scores, threshold):
    order = np.argsort(scores)[::-1]
    keep = []
    while order.size > 0:
        i = order[0]
        keep.append(i)
        ious = [iou(boxes[i], boxes[j]) for j in order[1:]]
        order = order[1:][np.array(ious) < threshold]
    return keep
```

**YOLOv8 训练示例**：
```python
from ultralytics import YOLO

# 加载预训练模型
model = YOLO('yolov8n.pt')

# 训练
model.train(
    data='coco128.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    lr0=0.01,
    device=0
)

# 推理
results = model('test.jpg')
```

**评估指标**：
- **mAP@0.5**: IoU=0.5 时的平均精度
- **mAP@0.5:0.95**: IoU 从 0.5 到 0.95 步进 0.05 的平均

### 任务 3：语义分割

**任务定义**：给每个像素分类

**U-Net 架构**：
```
输入 → [Encoder 下采样] → [Bottleneck] → [Decoder 上采样] → 输出
              ↓                              ↑
              └─── 跳跃连接 (Skip Connection) ─┘
```

```python
class UNet(nn.Module):
    def __init__(self, n_classes):
        super().__init__()
        # 编码器
        self.enc1 = self.conv_block(3, 64)
        self.enc2 = self.conv_block(64, 128)
        # 解码器
        self.dec1 = self.upconv_block(128, 64)
        self.final = nn.Conv2d(64, n_classes, 1)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(F.max_pool2d(e1, 2))
        d1 = self.dec1(e2)
        # 跳跃连接
        d1 = torch.cat([d1, e1], dim=1)
        return self.final(d1)
```

**评估指标**：
- **IoU (Jaccard Index)**
- **Dice Coefficient**
- **Pixel Accuracy**
