## 📖 核心网络详解

### 1. ResNet 残差网络

**核心思想**：通过跳跃连接解决深度网络退化问题

```python
class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride, 1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride),
                nn.BatchNorm2d(out_channels)
            )

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # 残差连接
        return torch.relu(out)
```

**ResNet 演进**：

| 网络 | 层数 | Top-1 错误率 | 参数量 |
|------|------|-------------|--------|
| ResNet-18 | 18 | 30.43% | 11.7M |
| ResNet-34 | 34 | 26.70% | 21.8M |
| ResNet-50 | 50 | 23.85% | 25.6M |
| ResNet-101 | 101 | 22.63% | 44.5M |
| ResNet-152 | 152 | 21.69% | 60.2M |

### 2. MobileNet 轻量化网络

**核心思想**：深度可分离卷积大幅减少参数量

```python
class DepthwiseSeparableConv(nn.Module):
    def __init__(self, in_ch, out_ch, stride):
        super().__init__()
        # 深度卷积：每个输入通道单独卷积
        self.dw = nn.Conv2d(in_ch, in_ch, 3, stride, 1, groups=in_ch)
        # 逐点卷积：1x1 卷积融合通道
        self.pw = nn.Conv2d(in_ch, out_ch, 1, 1, 0)

    def forward(self, x):
        return self.pw(self.dw(x))
```

**MobileNet V2 倒残差结构**：
```
输入 → 1x1 升维 → 3x3 DW → 1x1 降维 → 输出
       (扩展因子6)             (无激活)
```

### 3. EfficientNet

**核心思想**：复合缩放（同时缩放深度、宽度、分辨率）

```
深度: d = α^φ
宽度: w = β^φ  
分辨率: r = γ^φ
约束: α·β²·γ² ≈ 2
```

| 版本 | 参数量 | Top-1 |
|------|--------|-------|
| EfficientNet-B0 | 5.3M | 77.1% |
| EfficientNet-B1 | 7.8M | 79.1% |
| EfficientNet-B7 | 66M | 84.3% |

### 4. Vision Transformer (ViT)

**核心思想**：把图像切成 patch，当作 token 送入 Transformer

```python
class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_ch=3, embed_dim=768):
        super().__init__()
        self.proj = nn.Conv2d(in_ch, embed_dim, patch_size, patch_size)
        # 224/16 = 14, 14*14 = 196 patches

    def forward(self, x):
        x = self.proj(x)  # (B, 768, 14, 14)
        x = x.flatten(2)  # (B, 768, 196)
        x = x.transpose(1, 2)  # (B, 196, 768)
        return x
```

**ViT 流程**：
```
图像 → 切分为 16x16 patches → Linear 投影 → 加上位置编码
   → Transformer Encoder → MLP Head → 分类
```

### 5. YOLO 目标检测

**YOLO 核心思想**：
- 把图像划分为 S×S 网格
- 每个网格预测 B 个边界框
- 每个边界框包含 5 个值（x, y, w, h, confidence）
- 每个网格预测 C 个类别概率

**YOLO 演进路线**：
```
YOLOv1 (2016) → v2 (2017) → v3 (2018) → v4 (2020) → v5 (2020)
   ↓
YOLOv8 (2023) → YOLOv9 (2024) → YOLOv10 (2024, NMS-free)
```

**YOLOv10 创新**：
- 干掉 NMS 过程
- 一致性双重分配
- 轻量化分类头
