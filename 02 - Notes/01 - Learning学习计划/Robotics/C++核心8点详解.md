# C++ 核心 8 点详解（ROS 2 方向）

> [!abstract] 摘要
> 把 ROS 2 / MoveIt 2 编程必需的 **8 个 C++ 核心点**讲透。每个点采用「**一句话定义 + 为什么 ROS 2 要用 + 最小例子 + ROS 2 实战**」结构，学完即可读懂 MoveIt 2 源码。

---

## 1. 指针 / 引用 / 智能指针（`shared_ptr`）

### 一句话定义

> **指针**：存"内存地址"的变量
> **引用**：变量的"别名"
> **智能指针**：自动管理内存的指针（`shared_ptr`、`unique_ptr`）

### 为什么 ROS 2 要用？

ROS 2 的节点、订阅者、发布者、Timer **几乎全部用 `shared_ptr`**：

```cpp
// ROS 2 中最常见的写法
auto node = std::make_shared<MyNode>();
rclcpp::spin(node);
```

如果不用智能指针，节点对象会**内存泄漏**（忘记 delete）或**悬空指针**（对象已销毁还在用）。

### 三者对比

```cpp
// 1. 原始指针（不推荐）
MyClass* p = new MyClass();  // 需手动 delete
delete p;

// 2. 引用（别名，不能改指向）
int a = 10;
int& ref = a;   // ref 就是 a
ref = 20;       // a 也变成 20

// 3. 智能指针
std::unique_ptr<MyClass> up = std::make_unique<MyClass>();   // 独占所有权
std::shared_ptr<MyClass> sp = std::make_shared<MyClass>();   // 可共享所有权
```

### ROS 2 实战

```cpp
#include <memory>
#include "rclcpp/rclcpp.hpp"

class MyNode : public rclcpp::Node {
public:
    MyNode() : Node("my_node") {
        // shared_ptr：发布者由多个对象共享
        publisher_ = this->create_publisher<std_msgs::msg::String>("topic", 10);
    }
private:
    // 必须用 shared_ptr，不能用原始指针
    rclcpp::Publisher<std_msgs::msg::String>::SharedPtr publisher_;
};

int main(int argc, char * argv[]) {
    rclcpp::init(argc, argv);
    // make_shared 创建并返回 shared_ptr
    rclcpp::spin(std::make_shared<MyNode>());
    rclcpp::shutdown();
    return 0;
}
```

> [!tip] 关键 API
> - `std::make_shared<T>(args...)`：创建 shared_ptr
> - `std::make_unique<T>(args...)`：创建 unique_ptr
> - `.use_count()`：查看引用计数
> - `.reset()`：释放所有权

## 2. 类 / 继承 / 多态

### 一句话定义

> **类**：自定义数据类型
> **继承**：子类复用父类成员
> **多态**：父类指针调用子类方法

### 为什么 ROS 2 要用？

**ROS 2 中所有节点都继承自 `rclcpp::Node`**：

```cpp
class MyNode : public rclcpp::Node { ... };
```

这是继承最经典的应用——你的节点"是一个 ROS 2 节点"，自动拥有父类的所有能力。

### 最小例子

```cpp
#include <iostream>
#include <string>

// 父类（基类）
class Animal {
public:
    // 虚函数：实现多态的关键
    virtual void speak() const {
        std::cout << "..." << std::endl;
    }
    virtual ~Animal() = default;  // 虚析构，必加
};

// 子类（派生类）
class Dog : public Animal {
public:
    void speak() const override {
        std::cout << "Woof!" << std::endl;
    }
};

class Cat : public Animal {
public:
    void speak() const override {
        std::cout << "Meow!" << std::endl;
    }
};

// 多态：父类指针指向子类对象
void make_speak(const Animal& a) {
    a.speak();  // 实际调用 Dog::speak 或 Cat::speak
}

int main() {
    Dog d;
    Cat c;
    make_speak(d);  // 输出 Woof!
    make_speak(c);  // 输出 Meow!
}
```

### ROS 2 实战

```cpp
#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/string.hpp"

// 继承自 rclcpp::Node
class Talker : public rclcpp::Node {
public:
    Talker() : Node("talker"), count_(0) {
        publisher_ = this->create_publisher<std_msgs::msg::String>(
            "chatter", 10);
        timer_ = this->create_wall_timer(
            std::chrono::milliseconds(500),
            std::bind(&Talker::callback, this));
    }
private:
    void callback() {
        auto msg = std_msgs::msg::String();
        msg.data = "Hello #" + std::to_string(count_++);
        publisher_->publish(msg);
    }
    rclcpp::Publisher<std_msgs::msg::String>::SharedPtr publisher_;
    rclcpp::TimerBase::SharedPtr timer_;
    size_t count_;
};
```

> [!warning] 易错点
> - 父类析构函数必须 `virtual`（防止内存泄漏）
> - 子类重写必须加 `override`
> - 构造时用**初始化列表** `: Node("name")` 而不是函数体赋值

## 3. 模板（Template）

### 一句话定义

> **模板**：编写"与类型无关"的通用代码，编译器在用时自动生成具体类型版本

### 为什么 ROS 2 要用？

ROS 2 消息是**泛型容器**，所有发布者/订阅者都用模板：

```cpp
rclcpp::Publisher<std_msgs::msg::String>::SharedPtr pub;  // String 类型
rclcpp::Publisher<geometry_msgs::msg::Pose>::SharedPtr pose_pub;  // Pose 类型
```

如果不用模板，每个消息类型都要写一遍发布者代码——不可能。

### 最小例子

```cpp
#include <iostream>
#include <string>

// 模板函数：支持任意类型
template<typename T>
T add(T a, T b) {
    return a + b;
}

// 模板类：通用容器
template<typename T>
class Box {
public:
    Box(T v) : value_(v) {}
    T get() const { return value_; }
private:
    T value_;
};

int main() {
    std::cout << add(3, 4) << std::endl;        // int
    std::cout << add(1.5, 2.5) << std::endl;    // double
    Box<int> b1(10);
    Box<std::string> b2("hello");
}
```

### ROS 2 实战

```cpp
// 模板实例化：发布 String 类型消息
auto pub = this->create_publisher<std_msgs::msg::String>("chatter", 10);

// 模板实例化：发布 Pose 类型消息
auto pose_pub = this->create_publisher<geometry_msgs::msg::Pose>("target", 10);

// 通用订阅回调模板
template<typename T>
void subscribe_topic(const std::string& topic) {
    auto sub = this->create_subscription<T>(
        topic, 10,
        [this](const typename T::SharedPtr msg) {
            RCLCPP_INFO(this->get_logger(), "Received");
        }
    );
}
```

> [!tip] 模板关键概念
> - `template<typename T>` 或 `template<class T>`（两者等价）
> - `T::SharedPtr`：依赖类型，必须加 `typename` 关键字
> - 模板代码在头文件（`.hpp`），不能分离编译

## 4. STL 容器（`vector`、`map`）

### 一句话定义

> STL = Standard Template Library，**C++ 自带的"积木箱"**，最常用的是 `vector`（动态数组）和 `map`（键值对）

### 为什么 ROS 2 要用？

```cpp
// 轨迹点：std::vector
std::vector<geometry_msgs::msg::Pose> waypoints;

// 关节角度映射：关节名 → 角度
std::map<std::string, double> joint_positions;
```

### 最小例子

```cpp
#include <vector>
#include <map>
#include <string>
#include <iostream>

int main() {
    // ========== vector：动态数组 ==========
    std::vector<int> scores = {90, 85, 78};
    scores.push_back(95);                 // 追加
    std::cout << scores[0] << std::endl;  // 下标访问：90
    std::cout << scores.size() << std::endl;  // 大小：4
    for (int s : scores) {                // 范围 for
        std::cout << s << " ";
    }

    // ========== map：键值对 ==========
    std::map<std::string, double> joint_angles;
    joint_angles["shoulder_pan"] = 0.0;
    joint_angles["shoulder_lift"] = -1.57;
    std::cout << joint_angles["shoulder_pan"] << std::endl;

    // 遍历 map
    for (const auto& [name, angle] : joint_angles) {
        std::cout << name << ": " << angle << std::endl;
    }
}
```

### ROS 2 实战

```cpp
#include <vector>
#include <map>
#include "geometry_msgs/msg/pose.hpp"
#include "trajectory_msgs/msg/joint_trajectory.hpp"

class Planner : public rclcpp::Node {
public:
    void plan_path() {
        // vector：存储多个目标位姿
        std::vector<geometry_msgs::msg::Pose> waypoints;
        geometry_msgs::msg::Pose p1;
        p1.position.x = 0.3; p1.position.y = 0.0; p1.position.z = 0.5;
        waypoints.push_back(p1);

        // map：关节名 → 目标角度
        std::map<std::string, double> target_joints = {
            {"joint1", 0.0},
            {"joint2", -1.57},
            {"joint3", 1.57}
        };

        // 访问 map
        for (const auto& [name, angle] : target_joints) {
            RCLCPP_INFO(this->get_logger(), "%s: %f", name.c_str(), angle);
        }
    }
};
```

> [!tip] 常用容器速查
>
> | 容器 | 用途 | 访问方式 |
> |------|------|---------|
> | `vector<T>` | 动态数组 | `v[i]`、`v.push_back(t)` |
> | `map<K,V>` | 有序键值对 | `m[k]`、`m.count(k)` |
> | `unordered_map<K,V>` | 哈希键值对（更快） | 同 map |
> | `set<T>` | 有序集合 | `s.insert(t)`、`s.count(t)` |
> | `string` | 字符串 | `s.size()`、`s.substr()` |

## 5. Lambda 表达式（回调）

### 一句话定义

> **Lambda** = 在**使用处**直接定义的"无名小函数"，适合一次性回调

### 为什么 ROS 2 要用？

ROS 2 的订阅回调、定时器、Service 处理函数**几乎都用 lambda**：

```cpp
timer_ = this->create_wall_timer(
    std::chrono::milliseconds(500),
    [this]() { /* 回调 */ }   // lambda
);
```

### 最小例子

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    // 1. 无捕获 lambda
    auto hello = []() {
        std::cout << "Hello" << std::endl;
    };
    hello();

    // 2. 带参数
    auto add = [](int a, int b) {
        return a + b;
    };
    std::cout << add(3, 4) << std::endl;

    // 3. 捕获外部变量
    int factor = 10;
    auto multiply = [factor](int x) {
        return x * factor;
    };
    std::cout << multiply(5) << std::endl;  // 50

    // 4. 引用捕获 [&] 可以修改外部变量
    int counter = 0;
    auto inc = [&counter]() { counter++; };
    inc(); inc();
    std::cout << counter << std::endl;  // 2

    // 5. STL 算法中常用
    std::vector<int> v = {3, 1, 4, 1, 5};
    std::sort(v.begin(), v.end(), [](int a, int b) {
        return a > b;  // 降序
    });
}
```

### 捕获语法速查

| 写法 | 含义 |
|------|------|
| `[]` | 不捕获任何外部变量 |
| `[=]` | 值捕获（拷贝）所有外部变量 |
| `[&]` | 引用捕获所有外部变量 |
| `[x]` | 仅值捕获 x |
| `[&x]` | 仅引用捕获 x |
| `[this]` | 捕获当前类的 this 指针 |

### ROS 2 实战

```cpp
class MyNode : public rclcpp::Node {
public:
    MyNode() : Node("my_node") {
        // 定时器 lambda 回调
        timer_ = this->create_wall_timer(
            std::chrono::milliseconds(500),
            [this]() {  // 捕获 this 指针
                this->timer_callback();
            }
        );

        // 订阅者 lambda 回调
        sub_ = this->create_subscription<std_msgs::msg::String>(
            "topic", 10,
            [this](const std_msgs::msg::String::SharedPtr msg) {
                RCLCPP_INFO(this->get_logger(), "Received: %s",
                            msg->data.c_str());
            }
        );

        // 服务 lambda 处理
        auto service = this->create_service<std_srvs::srv::Trigger>(
            "my_service",
            [this](
                const std_srvs::srv::Trigger::Request::SharedPtr req,
                std_srvs::srv::Trigger::Response::SharedPtr res
            ) {
                res->success = true;
                res->message = "OK";
            }
        );
    }
private:
    void timer_callback() { /* ... */ }
    rclcpp::TimerBase::SharedPtr timer_;
    rclcpp::Subscription<std_msgs::msg::String>::SharedPtr sub_;
};
```

> [!warning] 捕获陷阱
> - 不要 `[&]` 捕获 shared_ptr 后传出 lambda（悬空）
> - `this` 指针要在对象存活期内使用
> - lambda 内部默认 const，加 `mutable` 才能修改值捕获的变量

## 6. 命名空间（`namespace`）

### 一句话定义

> **命名空间**：防止名字冲突的"作用域隔离"。ROS 2 代码中**几乎每行都有命名空间**

### 为什么 ROS 2 要用？

ROS 2 的 API 都在 `rclcpp::` 命名空间下：
- `rclcpp::Node`
- `rclcpp::Publisher<T>`
- `rclcpp::spin()`

没有命名空间，几百个类同名就乱了。

### 最小例子

```cpp
#include <iostream>

// 自定义命名空间
namespace my_robot {
    class Arm { /* ... */ };
    class Gripper { /* ... */ };

    namespace utils {
        double deg2rad(double d) { return d * 3.14159 / 180; }
    }
}

int main() {
    // 方式 1：完整路径
    my_robot::Arm arm;
    my_robot::utils::deg2rad(90);

    // 方式 2：using 引入
    using my_robot::Arm;
    Arm arm2;

    // 方式 3：using namespace（不推荐在大项目用）
    using namespace my_robot::utils;
    deg2rad(45);
}
```

### ROS 2 实战

```cpp
// ROS 2 中常见命名空间
rclcpp::Node::SharedPtr node;          // rclcpp
std_msgs::msg::String msg;             // std_msgs::msg
geometry_msgs::msg::Pose pose;         // geometry_msgs::msg
sensor_msgs::msg::Image image;         // sensor_msgs::msg
tf2::Quaternion q;                     // tf2
Eigen::Matrix4d mat;                   // Eigen

// 头文件引入
#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/string.hpp"
#include "geometry_msgs/msg/pose.hpp"
```

> [!tip] 命名空间使用建议
> - 头文件**不要**写 `using namespace xxx;`（污染全局）
> - 实现文件可以用 `using namespace rclcpp;` 简化代码
> - 自定义类应放入自己的命名空间，避免与 ROS 2 冲突

## 7. CMake 构建

### 一句话定义

> **CMake** = 跨平台构建工具，ROS 2 用它编译所有 C++ 包

### 为什么 ROS 2 要用？

每个 ROS 2 包必须有 `CMakeLists.txt`，告诉编译器：
- 这个包叫什么
- 依赖哪些库
- 编译哪些源文件
- 生成哪些可执行文件

### 最小 CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)
project(my_first_pkg)

# 1. 找依赖
find_package(rclcpp REQUIRED)
find_package(std_msgs REQUIRED)

# 2. 添加可执行文件
add_executable(talker src/talker.cpp)

# 3. 链接依赖（推荐用 ament_target_dependencies）
ament_target_dependencies(talker rclcpp std_msgs)

# 4. 安装到指定目录
install(TARGETS talker
        DESTINATION lib/${PROJECT_NAME}
)
```

### 关键指令速查

| 指令 | 作用 |
|------|------|
| `cmake_minimum_required` | 指定最低 CMake 版本 |
| `project(name)` | 包名 |
| `find_package(...)` | 查找依赖 |
| `add_executable(name src)` | 生成可执行文件 |
| `add_library(name src)` | 生成库 |
| `ament_target_dependencies(target dep1 dep2)` | 链接 ROS 依赖 |
| `ament_package()` | 标记为 ROS 2 包 |
| `install(TARGETS ... DESTINATION ...)` | 安装目标 |

### 完整 ROS 2 包结构

```
my_first_pkg/
├── CMakeLists.txt
├── package.xml           # 包描述
├── src/
│   └── talker.cpp
├── include/
│   └── my_first_pkg/
│       └── talker.hpp    # 头文件
└── launch/
    └── talker.launch.py
```

### 配套 `package.xml`

```xml
<?xml version="1.0"?>
<?xml-model
  href="http://download.ros.org/schema/package_format3.xsd"
  schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>my_first_pkg</name>
  <version>0.1.0</version>
  <description>My first ROS 2 package</description>
  <maintainer email="me@example.com">Me</maintainer>
  <license>Apache-2.0</license>

  <depend>rclcpp</depend>
  <depend>std_msgs</depend>
</package>
```

### 构建命令

```bash
cd ~/ros2_ws
colcon build --packages-select my_first_pkg
source install/setup.bash
ros2 run my_first_pkg talker
```

> [!warning] 常见 CMake 错误
> - `ament_target_dependencies` vs `target_link_libraries`：优先前者（ROS 2 专用）
> - 头文件必须放在 `include/<package_name>/` 下，避免冲突
> - 修改 `CMakeLists.txt` 后必须重新 `colcon build`

## 8. 异常处理

### 一句话定义

> **异常** = 程序遇到错误时"抛出"信号，由调用者"捕获"处理，不让程序崩溃

### 为什么 ROS 2 要用？

ROS 2 中遇到参数错误、网络断开、初始化失败等情况，必须**优雅处理**，不能让节点直接崩溃退出整个系统。

### 最小例子

```cpp
#include <iostream>
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0) {
        throw std::runtime_error("Division by zero!");  // 抛出
    }
    return a / b;
}

int main() {
    try {
        std::cout << divide(10, 0) << std::endl;
    } catch (const std::runtime_error& e) {  // 捕获
        std::cerr << "Error: " << e.what() << std::endl;
    }
    std::cout << "继续执行" << std::endl;
}
```

### 常用异常类型

| 类型 | 触发场景 |
|------|---------|
| `std::runtime_error` | 运行时错误（最常用） |
| `std::invalid_argument` | 参数无效 |
| `std::out_of_range` | 越界访问（如 vector[i]） |
| `std::bad_alloc` | 内存分配失败 |
| `std::exception` | 所有异常的基类 |

### 异常处理三关键字

```cpp
try {
    // 可能出错的代码
    risky_function();
} catch (const std::exception& e) {
    // 捕获所有异常
    std::cerr << "Caught: " << e.what() << std::endl;
}

// 也可以主动抛出
if (something_wrong) {
    throw std::runtime_error("oops");
}
```

### ROS 2 实战

```cpp
#include <stdexcept>
#include "rclcpp/rclcpp.hpp"
#include "geometry_msgs/msg/pose.hpp"

class RobotController : public rclcpp::Node {
public:
    RobotController() : Node("robot_controller") {
        try {
            // 尝试初始化硬件
            initialize_hardware();
        } catch (const std::runtime_error& e) {
            RCLCPP_ERROR(this->get_logger(),
                         "硬件初始化失败: %s", e.what());
            // 进入安全模式
            enter_safe_mode();
        }
    }

    void move_to(const geometry_msgs::msg::Pose& target) {
        try {
            // 参数检查
            if (target.position.x < 0 || target.position.x > 1.0) {
                throw std::invalid_argument("x 超出工作空间");
            }
            // 执行规划
            execute_motion(target);
        } catch (const std::invalid_argument& e) {
            RCLCPP_WARN(this->get_logger(), "参数错误: %s", e.what());
            return;
        } catch (const std::exception& e) {
            RCLCPP_ERROR(this->get_logger(), "执行失败: %s", e.what());
            // 急停
            emergency_stop();
        }
    }

private:
    void initialize_hardware() {
        // 假装硬件初始化失败
        throw std::runtime_error("串口未找到");
    }
    void execute_motion(const geometry_msgs::msg::Pose& p) {}
    void enter_safe_mode() {}
    void emergency_stop() {}
};
```

> [!warning] 异常使用准则
> - 不要用异常处理**正常的控制流**（性能差）
> - 不要在析构函数中抛出异常（会导致程序崩溃）
> - 析构、swap、资源释放**绝不抛异常**
> - 构造函数失败首选**抛出异常**而不是返回错误码

## 综合实战：MoveIt 2 源码阅读示例

下面这段代码综合用了 **8 个核心点**，是 MoveIt 2 简化版的节点：

```cpp
#include <memory>                              // 智能指针
#include <vector>                              // STL
#include <map>                                 // STL
#include <stdexcept>                           // 异常
#include "rclcpp/rclcpp.hpp"                   // 命名空间
#include "geometry_msgs/msg/pose.hpp"          // 模板消息
#include "moveit/planning_scene/planning_scene.hpp"  // 多态

namespace my_robot {  // 自定义命名空间
class MotionPlanner : public rclcpp::Node {   // 继承
public:
    MotionPlanner() : Node("motion_planner") {
        // 智能指针管理发布者
        publisher_ = this->create_publisher<geometry_msgs::msg::Pose>(
            "target_pose", 10);

        // lambda + this 捕获
        timer_ = this->create_wall_timer(
            std::chrono::seconds(1),
            [this]() { this->plan_and_publish(); }
        );

        // STL 容器：vector 存轨迹点
        waypoints_ = std::vector<geometry_msgs::msg::Pose>();

        // STL 容器：map 存关节角度
        home_position_ = std::map<std::string, double>{
            {"joint1", 0.0}, {"joint2", -1.57}
        };
    }

private:
    // 多态：通过基类指针调用派生类方法
    std::shared_ptr<moveit::planning_interface::MoveGroupInterface> move_group_;

    rclcpp::Publisher<geometry_msgs::msg::Pose>::SharedPtr publisher_;  // 智能指针
    rclcpp::TimerBase::SharedPtr timer_;
    std::vector<geometry_msgs::msg::Pose> waypoints_;                   // 模板消息 vector
    std::map<std::string, double> home_position_;                      // STL map

    void plan_and_publish() {
        try {
            geometry_msgs::msg::Pose target;
            target.position.x = 0.3;
            publisher_->publish(target);
        } catch (const std::exception& e) {
            RCLCPP_ERROR(this->get_logger(), "规划失败: %s", e.what());
        }
    }
};
}  // namespace my_robot

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    try {
        auto node = std::make_shared<my_robot::MotionPlanner>();
        rclcpp::spin(node);
    } catch (const std::exception& e) {
        std::cerr << "节点启动失败: " << e.what() << std::endl;
        return 1;
    }
    rclcpp::shutdown();
    return 0;
}
```

**这段代码用了所有 8 个核心点**：
1. ✅ 智能指针：`std::make_shared`、`::SharedPtr`
2. ✅ 继承：`public rclcpp::Node`
3. ✅ 模板：`Publisher<geometry_msgs::msg::Pose>`
4. ✅ STL：`vector`、`map`
5. ✅ Lambda：`[this]() { ... }`
6. ✅ 命名空间：`namespace my_robot`、`rclcpp::`
7. ✅ CMake：编译时通过 `ament_target_dependencies` 链接
8. ✅ 异常：`try/catch`、`std::exception`
