## 💡 学习方法

1. **计划驱动**：先看计划页，再做笔记
2. **理论与实战并重**：每个知识点都要写代码
3. **周复盘**：每周日总结，更新进度
4. **项目驱动**：每个阶段必有项目
5. **笔记归档**：技术笔记按规则归档
