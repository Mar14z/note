## 1. 头文件

### 1.1 头文件保护

**作用**：防止头文件被重复包含导致编译错误

```c
#ifndef HEADER_NAME_H
#define HEADER_NAME_H

// 头文件内容

#endif
```

**原理**：
1. 第一次包含 → 进入内容
2. 再次包含 → 已定义，跳过内容

### 1.2 头文件引用方式

| 写法 | 含义 | 示例 |
|------|------|------|
| `#include <stdio.h>` | 系统头文件 | 编译器自带 |
| `#include "myheader.h"` | 本地头文件 | 项目内 |
| `#include "../inc/common.h"` | 相对路径 | 跨目录 |

### 1.3 常见错误

| 错误写法 | 正确写法 | 原因 |
|---------|---------|------|
| `#include "stdio.h"` | `#include <stdio.h>` | 系统头文件应用尖括号 |
| `#include "../inc/abc.h"` | 检查路径 | 相对路径要正确 |

## 2. 宏定义

### 2.1 基本语法

```c
#define 名称 值
```

### 2.2 常用示例

```c
#define PROGRAM_NAME "sysmonitor"
#define MAX_PATH_LEN 256
#define DEBUG_MODE 1
```

### 2.3 宏定义 vs 常量

| 特性 | 宏定义 | const常量 |
|------|--------|----------|
| 类型检查 | 无 | 有 |
| 内存占用 | 无（替换） | 有 |
| 调试 | 困难 | 容易 |

**何时使用宏定义**：
- 简单的文本替换
- 条件编译
- 函数式宏

## 3. main函数

### 3.1 标准形式

```c
int main(int argc, char *argv[]) {
    // 你的代码
    return 0;
}
```

### 3.2 参数说明

| 参数 | 含义 | 说明 |
|------|------|------|
| `argc` | argument count | 参数个数 |
| `argv` | argument vector | 参数数组 |

### 3.3 示例

```bash
./program -c -m 5
```

此时：
- `argc = 3`
- `argv[0] = "./program"` 程序名
- `argv[1] = "-c"` 参数1
- `argv[2] = "5"` 参数2

### 3.4 返回值

| 值 | 含义 |
|----|------|
| `0` | 正常退出 |
| `非0` | 错误退出 |

## 4. 编译基础

### 4.1 GCC编译流程

```bash
gcc -c main.c          # 编译 → .o 文件
gcc main.o -o program  # 链接 → 可执行文件
```

### 4.2 常用编译选项

| 选项 | 作用 |
|------|------|
| `-Wall` | 警告全部开启 |
| `-Wextra` | 额外警告 |
| `-std=c11` | 使用C11标准 |
| `-g` | 包含调试信息 |
| `-Ipath` | 添加头文件路径 |
| `-o file` | 指定输出文件名 |

### 4.3 头文件路径

```bash
gcc -c main.c -I../include
# -I 后面指定头文件目录
```
