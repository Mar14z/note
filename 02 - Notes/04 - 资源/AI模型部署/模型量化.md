# AI 模型量化

> 关于模型量化的基础知识总结
> 创建时间：2026-05-26

---

## 什么是模型量化

模型量化是将模型从高精度（FP32）转换为低精度（INT8/FP16）的过程，目的是减少模型大小、降低内存占用、提高推理速度。

---

## 量化类型对比

| 类型 | 精度 | 模型大小 | 推理速度 | 精度损失 |
|------|------|---------|---------|---------|
| FP32 | 32位浮点 | 100% | 1x | 无 |
| FP16 | 16位浮点 | 50% | 1.5-2x | 极小 |
| INT8 | 8位整数 | 25% | 2-4x | 轻微 |
| INT4 | 4位整数 | 12.5% | 4-8x | 可能明显 |

---

## 是否需要量化？

### ✅ 不需要量化的情况
- 服务器部署，资源充足
- 延迟不敏感
- 精度要求极高
- 小模型（<1GB）

### ⚠️ 需要量化的情况
- 边缘设备部署（手机、IoT）
- 移动端 APP
- 实时推理需求
- LLM 大模型（7B+）
- 降低部署成本

---

## 不同模型类型建议

| 模型类型 | 大小 | 建议 |
|---------|------|------|
| LLM (7B) | ~14GB | **强烈推荐 INT4/INT8** |
| LLM (70B) | ~140GB | **必须量化** |
| Embedding | 较小 | 可选，影响不大 |
| 图像分类 | 较小 | 可选，一般不需要 |
| 语音识别 | 中等 | 推荐 INT8 |

## 量化实战代码

### PTQ（训练后量化）

```python
# PyTorch 静态量化
import torch.quantization as quant

model = MyModel()
model.eval()
model.qconfig = quant.get_default_qconfig('qnnpack')
quantized_model = quant.prepare(model, inplace=False)
quantized_model = quant.convert(quantized_model, inplace=False)
```

### QAT（量化感知训练）

```python
# 在训练时插入伪量化节点
model.qconfig = quant.get_default_qat_qconfig('qnnpack')
model = quant.prepare_qat(model)

for epoch in range(num_epochs):
    train(model)
quant.convert(model)  # 最后转换
```

### ONNX 量化

```python
from onnxruntime.quantization import quantize_dynamic, QuantType

quantize_dynamic(
    "model.onnx",
    "model_int8.onnx",
    weight_type=QuantType.QInt8
)
```

### 各框架量化

```python
# PyTorch 动态量化
torch.quantization.quantize_dynamic(model, {torch.nn.Linear}, dtype=torch.qint8)
```

```python
# TensorRT
config.set_flag(trt.BuilderConfig.FP16)  # 或 INT8
```

```bash
# llama.cpp

```

## 部署判断流程

```
1. 服务器 + 有 GPU + 不差钱 → 不量化 (FP32)
2. 服务器 + 内存紧张 → FP16
3. 边缘设备 / 移动端 / LLM → INT8/INT4
4. 对精度要求极高 → 不量化或混合精度
```
