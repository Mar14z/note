# AI 板端部署

> 边缘计算/嵌入式设备上的模型部署
> 创建时间：2026-05-26

---

## 常见板端设备

| 设备 | 算力 | 内存 | 适用场景 |
|------|------|------|---------|
| Jetson Nano | 0.5 TFLOPS | 4GB | 入门级 AI |
| Jetson Xavier | 11 TFLOPS | 16GB | 中端部署 |
| Jetson Orin | 275 TFLOPS | 64GB | 高端部署 |
| RK3588 | 6 TFLOPS | 8GB | 国产方案 |
| 昇腾 310 | 22 TFLOPS | 8GB | 华为生态 |
| 树莓派 + 加速棒 | 0.1 TFLOPS | 2-4GB | 轻量推理 |

## 板端部署工具链

### 框架选择

| 框架 | 官方支持 | 说明 |
|------|---------|------|
| TensorRT | NVIDIA | Jetson 专用，高效 |
| NCNN | 通用 | 移动端优化，支持 RK3588 |
| MNN | 阿里 | 轻量级，跨平台 |
| TFLite | Google | TensorFlow 移动端 |
| ONNX Runtime | 微软 | 支持多种硬件 |
| MindSpore | 华为 | 昇腾专用 |
| RKNN | 瑞芯微 | RK3588 专用 |

### 部署流程

```
服务器部署: PyTorch → ONNX → TensorRT → 推理

板端部署:   PyTorch → ONNX → 量化 → 板端框架 → 推理
                      ↓
                TensorRT / NCNN / RKNN
```

## RK3588 部署 (NCNN)

```bash
# 1. 安装 NCNN
git clone https://github.com/Tencent/ncnn.git
mkdir build && cd build
cmake -DNCNN_VULKAN=ON ..
make -j4

# 2. 模型转换: PyTorch → ONNX → NCNN
pytorch2ncnn model.onnx model.ncnn.param model.ncnn.bin

# 3. 部署
./ncnn/model.ncnn.param model.ncnn.bin
```

## 板端优化必备技术

### 1. 模型量化（必须）

```python
# TFLite 量化
converter = tf.lite.TFLiteConverter.from_saved_model(model_dir)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
converter.representative_dataset = representative_dataset
tflite_model = converter.convert()

# ONNX INT8 量化
from onnxruntime.quantization import quantize_dynamic
quantize_dynamic("model.onnx", "model_int8.onnx")
```

### 2. 模型剪枝

```python
import torch.nn.utils.prune as prune
prune.l1_unstructured(model.fc, name="weight", amount=0.3)
```

### 3. 知识蒸馏

```python
# 用大模型指导小模型训练
student_loss = loss(student_logits, labels)
distillation_loss = KL(student_logits, teacher_logits)
total_loss = alpha * student_loss + (1-alpha) * distillation_loss
```

## 板端 vs 服务器 关键差异

| 方面 | 服务器 | 板端 |
|------|--------|------|
| 精度 | FP32/FP16 | INT8/INT4 为主 |
| 内存 | GB 级 | MB 级 |
| 功耗 | 不限制 | 严格限制 |
| 工具链 | CUDA | 厂商 SDK |
| 优化 | 可选 | 必须 |
| 推理速度 | 快 | 需要优化 |

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 模型过大 | 没量化 | INT8 量化 |
| 推理太慢 | 模型复杂 | 剪枝/知识蒸馏 |
| 内存溢出 | 模型+数据 | 减小 batch size |
| 精度下降 | 量化过度 | 校准数据调优 |
| 框架不支持 | 算子不兼容 | 算子融合或改模型 |
