# 机械臂视觉抓取（RDK X5 + 双目相机）项目笔记

> RDK X5 上位机 + 双目摄像头（第三视角）+ 5 自由度机械臂（ArbotiX-M 控制）的视觉引导抓取系统
> 目标：让设备"理解空间"——识别机械臂自身位置与目标物体位置，实现自主抓取

## 📋 项目信息

| 属性 | 内容 |
|------|------|
| **项目名称** | 机械臂视觉抓取 |
| **下位机** | ArbotiX-M（ATMEGA644P）控制 5 自由度机械臂 |
| **舵机** | Dynamixel AX 系列，ID 1~5，COM6，115200 串口 |
| **上位机** | RDK X5（Bayes-e BPU，10 TOPS） |
| **视觉** | 双目摄像头，第三视角（eye-to-hand） |
| **任务** | 空间理解 + 目标定位 + 自主抓取 |
| **状态** | 🟡 进行中（下位机舵机已验证） |

## 🏗️ 系统架构

```mermaid
graph LR
    A[双目摄像头<br/>第三视角] --> B[双目深度估计<br/>视差→深度→点云]
    B --> C[目标检测<br/>YOLO 跑在 BPU]
    C --> D[目标 3D 定位<br/>像素+深度→相机系坐标]
    D --> E[坐标变换<br/>相机系→机械臂基座系]
    E --> F[逆运动学 IK<br/>目标点→关节角]
    F --> G[串口指令<br/>下发 ArbotiX-M]
    G --> H[机械臂抓取]
```

### 空间理解三层

| 层 | 解决什么 | 关键技术 |
|----|---------|---------|
| **感知层** | 目标在哪、机械臂在哪 | 双目深度 + YOLO 检测 |
| **坐标层** | 像素 → 机械臂能懂的 3D 坐标 | 相机标定 + 手眼标定 |
| **控制层** | 3D 坐标 → 关节转动 | 逆运动学 IK + 串口下发 |

> [!important] 核心难点
> 第三视角（eye-to-hand）下相机坐标系与机械臂基座坐标系不同，必须做**手眼标定**算出变换矩阵，这是最容易卡住的一步。

## 📝 进展日志

### 2026-10-07
- **ArbotiX-M 板子验证**：COM6 串口测试，LED ON/OFF 正常
- **单舵机测试**：位置读写、扭矩锁定、目标转动正常；发现默认满速危险，用 `dxlSetGoalSpeed` 限速（30≈3% 满速）
- **机械臂确认**：5 自由度，Dynamixel 舵机 ID 1~5
- **多舵机测试**：编写交互式测试程序（输入 ID 单测、`r` 全量扫描、`f` 扭矩全关、测试后自动归位 512）
- **疑难排查**：某关节"读得到角度但不动"，每次不同的关节 → 判断为 AX-12 过温/过流保护锁死，断电重启恢复
- **远程控制调研**：确认支持 XBee（板载插座）/ 蓝牙 / 上位机（RDK X5）三种远程方式，机械臂抓取走 RDK X5 上位机方案
- **视觉抓取立项**：确定双目第三视角方案，梳理架构与分阶段计划
