## 🎯 综合项目

### 项目：实时目标检测 Web 服务

**功能**：
- 浏览器上传图片
- 后端推理（YOLOv8 + TensorRT）
- 返回检测结果
- 显示带框图片

**技术栈**：
- 前端：HTML + JavaScript
- 后端：FastAPI
- 模型：YOLOv8s（INT8 量化）
- 部署：Docker + TensorRT

**性能目标**：推理延迟 < 50ms，支持 10+ QPS。

**实施步骤**：
1. 训练或下载 YOLOv8 模型
2. 转换为 ONNX → TensorRT
3. 编写 FastAPI 服务
4. 编写前端界面
5. Docker 打包
6. 性能测试
