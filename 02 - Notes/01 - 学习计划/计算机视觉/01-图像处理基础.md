### 2. 色彩空间（Color Space）

> [!info] 核心认知
> **RGB/BGR 是显示器语言，HSV 是人眼语言，灰度是简化版**。颜色追踪用 HSV，边缘检测用灰度，特殊需求才转 Lab/YUV。

#### 2.1 常用色彩空间全景

| 色彩空间 | 含义 | 典型用途 |
|---------|------|---------|
| **RGB** | 显示器标准（红绿蓝） | 显示、其他库 |
| **BGR** | OpenCV 默认（蓝绿红） | OpenCV 读写 |
| **灰度** | 单通道，只有亮度 | 边缘检测、特征提取 |
| **HSV** | 色相 + 饱和度 + 明度 | 颜色追踪、分割 |
| **Lab** | 感知均匀（高级） | 色差、色彩迁移 |
| **YUV** | 亮度 + 色度 | 视频压缩 |

#### 2.2 转换速查表

| 转换 | API | 用途 |
|------|-----|------|
| BGR → RGB | `cv2.COLOR_BGR2RGB` | matplotlib 显示 |
| BGR → 灰度 | `cv2.COLOR_BGR2GRAY` | 边缘检测、特征提取 |
| BGR → HSV | `cv2.COLOR_BGR2HSV` | 颜色追踪、分割 |
| 灰度 → BGR | `cv2.COLOR_GRAY2BGR` | 拼接显示 |
| HSV → BGR | `cv2.COLOR_HSV2BGR` | 显示结果 |

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
```

#### 2.3 BGR vs RGB（最常见的坑）

> [!warning] OpenCV 用 **BGR**，matplotlib / PIL 用 **RGB**
> 直接 `plt.imshow(img)` 会出现红蓝颠倒的“阿凡达色”。

```python
import cv2
import matplotlib.pyplot as plt

img = cv2.imread('photo.jpg')                   # BGR
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  # 转 RGB 才能用 matplotlib
plt.imshow(img_rgb)
plt.show()
```

#### 2.4 灰度图

- **是什么**：每个像素只有 0-255 的亮度值（单通道）
- **公式**：`Gray = 0.299*R + 0.587*G + 0.114*B`（人眼对绿最敏感）

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(gray.shape)  # (H, W) 没有通道维度了
```

用途：

- ✅ 边缘检测（Canny）
- ✅ 特征提取（SIFT、ORB）
- ✅ 减少计算量（3 通道 → 1 通道）
- ❌ 不能用于颜色相关任务

#### 2.5 HSV 色彩空间（重点）

- **H（Hue）色相**：颜色类型，OpenCV 中为 0-180°（实际角度减半）
- **S（Saturation）饱和度**：颜色鲜艳程度，0-255
- **V（Value）明度**：颜色明暗，0-255

> [!tip] 为什么 HSV 重要？
> RGB 受光照影响大；HSV 中 V 是亮度，H/S 受光照影响小，**最适合做颜色追踪**。

```python
# 蓝色范围（OpenCV HSV 范围）
lower_blue = np.array([100, 50, 50])
upper_blue = np.array([130, 255, 255])

mask = cv2.inRange(hsv, lower_blue, upper_blue)      # 生成掩码
result = cv2.bitwise_and(img, img, mask=mask)        # 提取蓝色区域
```

**常用颜色 HSV 范围**：

| 颜色 | H 范围 | S 范围 | V 范围 |
|------|--------|--------|--------|
| 🔴 红 | 0-10, 170-180 | 50-255 | 50-255 |
| 🟢 绿 | 35-85 | 50-255 | 50-255 |
| 🔵 蓝 | 100-130 | 50-255 | 50-255 |
| 🟡 黄 | 20-35 | 50-255 | 50-255 |
| ⚪ 白 | 任意 | 0-30 | 200-255 |
| ⚫ 黑 | 任意 | 0-255 | 0-30 |

> [!warning] 红色的特殊情况
> 红色跨 0°，需要分两段检测（0-10 和 170-180）。

#### 2.6 通道分离与合并

```python
# 分离
b, g, r = cv2.split(img)

# 只看蓝色通道
zeros = np.zeros_like(b)

# 合并

```

#### 2.7 实战：实时颜色检测器

```python
import cv2
import numpy as np

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    lower = np.array([100, 50, 50])
    upper = np.array([130, 255, 255])
    mask = cv2.inRange(hsv, lower, upper)
    result = cv2.bitwise_and(frame, frame, mask=mask)

    cv2.imshow('Original', frame)
    cv2.imshow('Mask', mask)
    cv2.imshow('Result', result)

    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

#### 2.8 常见坑

| 坑 | 解决方案 |
|----|---------|
| 颜色检测不到 | 调整 HSV 范围，用滑动条实时调 |
| H 范围对不上 | OpenCV 的 H 是 0-180，不是 0-360，要除以 2 |
| matplotlib 显示奇怪 | 记得 BGR → RGB |
| 受光照影响 | 用 HSV 而非 RGB |
| 红色范围特殊 | 跨 0°，分两段（0-10 和 170-180）检测 |

### 3. 图像滤波

```python
# 均值滤波
blur = cv2.blur(img, (5, 5))

# 高斯滤波
gaussian = cv2.GaussianBlur(img, (5, 5), 0)

# 中值滤波（去噪）
median = cv2.medianBlur(img, 5)

# 双边滤波（保边去噪）
bilateral = cv2.bilateralFilter(img, 9, 75, 75)
```

### 4. 边缘检测

```python
# Canny 边缘检测
edges = cv2.Canny(img, 100, 200)

# Sobel 算子
sobelx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=5)
sobely = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=5)

# Laplacian 算子
laplacian = cv2.Laplacian(gray, cv2.CV_64F)
```

### 5. 形态学操作

```python
kernel = np.ones((5, 5), np.uint8)

# 腐蚀
erosion = cv2.erode(img, kernel, iterations=1)

# 膨胀
dilation = cv2.dilate(img, kernel, iterations=1)

# 开运算（先腐蚀后膨胀）
opening = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)

# 闭运算（先膨胀后腐蚀）
closing = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)
```

### 6. 轮廓检测

```python
# 查找轮廓
contours, hierarchy = cv2.findContours(edges, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

# 绘制轮廓
cv2.drawContours(img, contours, -1, (0, 255, 0), 3)

# 轮廓特征
for cnt in contours:
    area = cv2.contourArea(cnt)
    perimeter = cv2.arcLength(cnt, True)
    x, y, w, h = cv2.boundingRect(cnt)
```
