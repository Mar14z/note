## 💡 说明

### ✅ 适合放在这里
- **技术指南**：某个技术的使用方法（不分阶段）
- **行业分析**：行业趋势、公司、市场
- **技术栈总结**：某个方向的工具链
- **转型指南**：从 A 方向转到 B 方向

### ❌ 不适合放在这里
- **分阶段的学习笔记** → 放 `01 - 学习计划/<领域>/`
- **项目笔记** → 放 `02 - 项目/`
- **资源链接** → 放 `04 - 资源/`
- **临时想法** → 放 `00 - 收集箱/`

### 🆕 新增领域流程
1. 在 `03 - 领域/<领域名>/` 下创建笔记
2. 在本 README 添加入口链接
3. 如果需要系统学习，在 `01 - 学习计划/` 创建学习计划
